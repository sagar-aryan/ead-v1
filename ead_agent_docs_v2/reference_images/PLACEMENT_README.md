# Required physical placement reference

Use `RIGHT_LEG_IMU_PLACEMENT.png` during physical assembly.

Required axes:
- X = forward toward toes
- Y = medial/left for the right leg
- Z = up/away from ground

Foot sensor: dorsum/midfoot, address 0x68.
Shank sensor: anterior/anteromedial lower shank, 10–15 cm below knee, address 0x69.

Both boards must face the same direction and be mounted rigidly.
